SUMMARY OF NETWORK DATA FLOWS
====================================================================================================
Flow 1 (User App Access)       : User -> CloudFront (443) -> S3 Frontend (apleshahar-frontend-...)
Flow 2 (API Operations)        : User -> CloudFront (/api/*) -> IGW -> EC2:5000 -> RDS:5432
Flow 3 (Image Upload & Resize) : User -> EC2 -> S3 Media (complaints/*) -> S3 Event -> Lambda -> S3
Flow 4 (Image Edge Viewing)    : User -> CloudFront (/complaints/*) -> S3 Media
Flow 5 (Transactional Alerts)  : EC2 Complaint Handler -> SNS Topic -> Email (apatade76@gmail.com)
Flow 6 (Secret Resolution)     : EC2 Boot -> IAM IMDSv2 -> SSM Parameter Store (/apleshahar/*)
Flow 7 (Metric Monitoring)     : EC2 CPU Usage -> CloudWatch Alarm (>75%) -> SNS Topic -> Alert Email
